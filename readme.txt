A simple yet powerful plugin to manage and track leads directly from your WordPress dashboard. Lightweight CRM functionality for small businesses.

== Description ==

WP Leads Management is a lightweight CRM plugin that allows you to capture, manage, and follow up on leads. Designed for simplicity and effectiveness, this plugin integrates seamlessly with your WordPress admin dashboard.

**Features:**
- Frontend lead capture form via shortcode `[wp_lead_form]`
- Admin panel to manage leads
- Export leads to CSV
- View lead details
- Lightweight and easy to use

Perfect for small business owners, marketers, and agencies who want to keep their lead management simple and inside WordPress.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate the plugin from the **Plugins** menu in WordPress.
3. Use the shortcode `[wp_lead_form]` on any post/page to display the form.
4. View and manage leads in the **WP Leads** section in your dashboard.

== Frequently Asked Questions ==

= Can I export leads? =
Yes, there is a built-in CSV export option in the admin panel.

= Can I customize the form? =
Currently, basic fields are provided. Customization options will be added in future versions.
