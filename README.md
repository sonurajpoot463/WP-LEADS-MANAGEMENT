# WP Leads Management

**WP Leads Management** is a powerful and easy-to-use WordPress plugin designed to manage and organize leads directly from your WordPress dashboard. Ideal for marketers, small businesses, and service providers, this plugin offers a simple CRM-like interface for capturing, viewing, and managing lead information.

---

## 🚀 Features

- Lead capture form with customizable fields
- Lead listing table in WordPress admin
- View individual lead details
- Export leads to CSV
- Responsive design and easy UI
- Lightweight and clean code
- Perfect for small-scale CRM and follow-up management

---

## 📦 Installation

1. Download the plugin ZIP or clone this repository.
2. Upload the plugin folder to the `/wp-content/plugins/` directory.
3. Activate the plugin through the **Plugins** menu in WordPress.
4. Go to **WP Leads > Settings** to configure.

---

## 📝 Usage

- Place the shortcode `[wp_lead_form]` anywhere on a page/post to show the lead capture form.
- Collected leads will appear in the **WP Leads** section of the admin panel.
- You can view, filter, and export leads from there.
